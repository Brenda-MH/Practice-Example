## 2. Objetivo del Sistema
Desarrollar una plataforma web que permita a los docentes crear, administrar y evaluar exámenes de manera eficiente, mientras que los estudiantes pueden responder cuestionarios en línea y obtener sus resultados de forma rápida y automática.

---

## 3. Problema que Resuelve
En muchos entornos educativos, la aplicación y calificación de exámenes se realiza de forma manual, lo que genera:

- Mayor tiempo de evaluación.
- Posibles errores en la calificación.
- Dificultad para almacenar y consultar resultados históricos.
- Limitaciones para manejar distintos tipos de preguntas en un mismo examen.

**Exam Quiz** resuelve estos problemas al digitalizar el proceso de evaluación, permitiendo la creación de exámenes con preguntas de opción múltiple, abiertas y de relación de columnas, además de almacenar y procesar automáticamente las respuestas de los estudiantes.

---

## 4. Tecnologías Utilizadas

### PHP
- Desarrollo de la lógica del sistema.
- Gestión de usuarios y autenticación.
- Procesamiento de exámenes y respuestas.
- Comunicación con la base de datos.

### MongoDB
- Almacenamiento flexible de exámenes y respuestas.
- Manejo eficiente de estructuras de datos anidadas.
- Soporte para diferentes tipos de preguntas dentro de un mismo documento.
- Uso del Aggregation Framework para calcular puntajes y generar estadísticas.

---

## 5. Conclusión
**Exam Quiz** es una solución moderna para la gestión de evaluaciones académicas. Gracias a la combinación de **PHP** y **MongoDB**, el sistema ofrece flexibilidad, rapidez y facilidad de administración, permitiendo optimizar el proceso de creación, aplicación y calificación de exámenes. Además, su capacidad para manejar distintos tipos de preguntas y calcular resultados automáticamente mejora significativamente la experiencia tanto de docentes como de estudiantes.
